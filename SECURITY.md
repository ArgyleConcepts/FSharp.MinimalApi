# Security policy

## Reporting a vulnerability

Use GitHub's [private vulnerability reporting](https://github.com/ArgyleConcepts/FSharp.MinimalApi/security/advisories/new) for this repository. Do not open a public issue or pull request containing an undisclosed vulnerability.

Include the affected version or commit, a minimal reproduction, expected impact, and any suggested fix. Remove real credentials and personal data. Maintainers will use the private advisory to discuss investigation, remediation, and disclosure with you. Response times depend on maintainer availability.

## Supported code

This .NET 10 fork is preparing its first Argyle Concepts package release. Security fixes currently target `develop`; no older version has a promised backport or long-term support commitment. See the README for publication status. Upstream packages published by other owners are outside this fork's release process.
